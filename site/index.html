url turns an HTTP address into a stable local path. run resolves it and gets out of the way.

zsh
$ run https://hydraulic-software.github.io/url/ hello
Hello from run.zip.
argument: hello

That URL is live. The directory convention selects run.zip/run.sh or run.zip/run.ps1 for the current platform.

01

URLs become paths

Files and members of nested archives resolve into a content cache. The printed path stays quiet enough for scripts.

jar=$(url example.com/app.zip/app.jar)
02

Directories become tools

A trailing slash means “find the conventional launcher.” Arguments pass through unchanged.

run example.com/tool/ --version
03

Integrity travels with the URL

Pin a download without a separate lock file. The fragment is checked locally and never sent to the server.

url example.com/a#sha256=<digest>

Install the command

Download one native binary, then let it make its second name.

$ chmod +x run
$ ./run --install

Builds are published for Linux and macOS on Intel and ARM. run --install creates the sibling url hard link and optional zsh integration.
